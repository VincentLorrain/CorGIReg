# V0 — initial integrated milestone

V0 combines the graph-import, pattern-matching and multithreading work on `dev`.
The Git tag `V0` identifies this source milestone; the Python CLI distribution
version remains `0.1.0`. This is an experimental baseline, not a stability promise
for every internal C++ API.

## Included capabilities

- JSON operation graphs, ONNX and textual StableHLO importers, with original
  source IDs, names and metadata retained in results.
- Graph patterns with common and strict nodes, forward/reverse syntax, quantified
  groups and explicit end assertions.
- Reusable JSON node definitions and typed NodeTest conditions for attributes,
  argument presence, value comparisons and regular expressions on strings/keys.
- JSON reports containing the complete pattern, ordered captures and nested
  quantifier invocation counts.
- A post-AST root-selection planning phase, independent of machine generation.
- Optional parallel starting-tuple search through `--jobs`, with ordered output
  and isolated per-tuple contexts. The default remains sequential.
- Windows/Linux installation scripts, example matching scripts, functional tests,
  reproducible performance reports and a linked documentation reference.

## Install and try

From a checkout of tag `V0`, run `python installation/install.py` for JSON support,
or `python installation/install.py --formats all` for optional ONNX and StableHLO
readers. See [installation prerequisites](../../installation/README.md).

After activating the installed environment:

```sh
corgireg -i doc/examples/graph.json -r 'A+->B->$' --jobs 4 -o matches.json
```

See [the documentation index](../README.md) for the language, data formats and
extension points, and [multithreading](../multithreading.md) for its measured
behavior and verification scope.

## Known limits

The merged source was built in Debug and passed all 58 discovered CTest tests
on Windows on 2026-10-23, including CLI, optional IR imports, parallel matching
and benchmark smoke checks. Local pre-existing edits were set aside during
this validation so the compiled sources match the versioned milestone.

Root selection currently proposes roots without rerooting execution; Cartesian
starting-tuple enumeration remains bounded by `--max-starts`. Parallelism reduces
elapsed time on suitable workloads but does not remove combinatorial growth.
Concurrent compilation and arbitrary mutable user callbacks are not supported
by the parallel-search contract. ThreadSanitizer has not been run in the local
Windows validation.

Importers implement documented subsets: nested ONNX graphs and region-bearing
StableHLO operations are unsupported. Graph adjacency does not preserve parallel
edge multiplicity or identify operand ports. Match reports contain node visits,
not an explicit matched-edge list. See [importers](../importers.md) and
[match reports](../match-report-json.md).

Large generated stress graphs under `local-tests/` are local-only fixtures and
are not distributed in this milestone.
